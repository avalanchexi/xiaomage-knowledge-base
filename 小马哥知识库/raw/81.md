# 81.奥运“梦之队”失利，创业板大跌5%，风险是体育和投资最大的魅力

- 作者：马永谙
- 发布时间：2021-07-27 00:00:00
- 来源：微信小程序详情页接口

（录制时间：2021-07-27）

昨天真是让人郁闷的一天，白天A股大跌，跳水梦之队失利，晚上乒乓球竟然还输给了日本。

跳水怎么会输呢？乒乓球怎么会输呢？在大家的“一致预期”里，这些都是绝对不会输的项目啊。

这其实就是体育的魅力：没有任何结果是确定的，当你走向顶峰的时候，也意味着随时可能会走下领奖台。乒乓球打得好，自然被敌人研究的多，许昕的乒乓球技术被全世界研究，这就是你在顶峰的代价。要维持在顶峰，需要付出更多的努力，当然也会面临更大的挑战和风险。

这和投资是很像的。股市里也有很多类似的情景，上涨一段时间后，人们会形成一致性的上涨预期，这时候也往往也就是风险最高的时候。越高的收益，意味着越高的风险，在金融领域，者有一个专门的词，叫“盈亏同源”：同样一个因素，既能短期给你带来超预期收益，也能在几天之内让你亏的老娘都不认识。

举个简单的例子，去年的猪肉股让一大票专注于农林牧渔的基金暴涨，可是今年的收益就变成“愁云惨淡万里凝”了，这些基金的持股有变化吗？没有，引起基金暴跌的原因正是触发基金暴涨的原因。

切记切记，在金融领域，谁只向你介绍收益，不认真向你介绍风险，谁只介绍一个短期的收益，却不介绍长期的收益，谁就是骗你的钱。

我们要远离坏人。

当然，在投资领域中，仅仅知道“没有无风险的收益”，只能保证你不被骗，要想赚钱，还得深刻理解收益和风险的来源。
我们看到很多基金组合在去年都表现得非常好，这是因为他们持有了高比例的股票，这是收益来源，但同时也带来了风险，在市场下跌的时候，这些基金组合往往跌幅过大，容易击穿我们的底线，让咱们承受不住，最终导致亏损。

梦之队失利让人沮丧，但持有魔方组合的人，即便这种市场下跌，也很安稳。为啥呢？就是因为我们知道“人力有穷尽”，人无法预测市场，正如你无法预测今天梦之队的失利。但我们可以通过组合，让下跌带来的损失少，让我们在下跌中舒适。正如中国乒乓球之所以是宇宙第一强，是因为队员风格多样、整体实力很强，所以从来不惧怕任何的单一的失利。

理解风险与收益的来源后，我们就可以去接受不确定性，去拥抱风险了。有些人往往极端厌恶风险，所有的钱都存在银行，其实风险与收益是同源的，极端厌恶风险的同时，存在银行的钱被通货膨胀收割了，最终还是承担了风险。我一直讲，隐形的贬值才是最大的风险，因为它每时每刻都在发生，都在消耗你的财富。极端厌恶风险其实大可不必，风险中往往孕育着机会，危机危机，危中有机，咱们得明白，市场下跌有风险，踏空市场更是风险。
没有人能够准确预测市场，我们唯一能做的，就是在了解了所有可能的收益与风险之后，静静的待在市场里，用开放的心态去迎接每一次上涨与下跌。

况且，塞翁失马焉知非福，很多时候我们其实很难判断一件事到底是好是坏，假设国乒混双赢了，本届奥运会继续包揽全部的金牌，这就一定是好事儿吗？不一定，这反倒有可能导致乒乓球被移出奥运项目。其实，只要知道咱们国乒的训练体系还是世界顶尖，运动员人才还在源源不断的冒出来，一次两次的失利就不算什么，咱们就还能一直看好国乒。同样，市场大跌就一定是坏事吗？不一定，在我看来，理解了魔方资产配置的逻辑体系之后，知道了自己承担的风险极限之后，市场大跌反倒更是一个好的加仓机会。
