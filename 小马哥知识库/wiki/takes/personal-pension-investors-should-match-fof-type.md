# 个人养老金应按年龄和风险匹配养老 FOF

## 论断
251 号文稿认为，个人养老金账户的长期价值要通过合适的产品匹配实现。年轻、收入稳定、风险承受力较高的人可以承受更高权益比例；临近退休或收入不稳定的人则应优先降低波动。
