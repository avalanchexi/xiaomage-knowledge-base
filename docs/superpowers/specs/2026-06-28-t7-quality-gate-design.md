## 三层检查(客观→语义)

1. **完整性层(机械)** — raw↔source 1:1、空壳页、`derived-from` 可解析、frontmatter 齐全、`gbrain lint` 断链/孤儿。
2. **slug 一致层(机械+半语义)** — 同一实体跨篇同 slug、是否在冻结 `aliases.md`、有无分裂节点。
3. **take 忠实度层(语义·核心)** — claim 忠实原文、无幻觉/张冠李戴、`derived-from` 指对、无漏抽。

```
                 ▼

```

## 过线口径(严格档)

| 指标 | 分子÷分母 | 阈值 |
|---|---|---|
| 严重 | 全样本严重问题计数 | =0 |
| 中级命中率 | 中级问题数 ÷ 抽样总(take+event)条数 | ≤5% |
| slug 一致 | 一致实体引用 ÷ 总实体引用 | ≥98% |
| 噪声残留 | 有残留页数 ÷ 抽样总页数 | ≤5% |

定级:严重=幻觉/张冠李戴/derived-from 指错;中=漏关键观点·事件要素错;轻=噪声·slug 小不一致·frontmatter 小缺。
