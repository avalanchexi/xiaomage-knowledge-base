# 知识图谱深度扩展节点预算 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让检索深度 1/2/3/4 同时控制图谱检索半径和展示规模，使深度越大时能展示更多节点与关系。

**Architecture:** 保持 DeepSeek 只解析查询意图，图谱内容仍只来自本地 `graph-index.json`。在 `assemble.ts` 内把固定 `MAX_NODES/MAX_EDGES` 改为按深度计算的预算，并继续使用按层保留策略，避免“中国/美国/特朗普”等大节点的一层邻居挤满全部展示名额。

**Tech Stack:** TypeScript, Vite, Vitest, Cytoscape, 本地 JSON 图索引。

## Budget Design

深度与预算映射：

| Depth | Node Limit | Edge Limit | 用途 |
| --- | ---: | ---: | --- |
| 1 | 70 | 180 | 核心邻域 |
| 2 | 120 | 300 | 标准扩展 |
| 3 | 180 | 480 | 深层扩展 |
| 4 | 240 | 700 | 探索视图 |

`depth` 只接受 1-4。非法值在装配层降级为 2，保持和 UI 默认一致。

```ts
export const MAX_NODES = 70;
export const MAX_EDGES = 180;

export type GraphBudget = {
  nodeLimit: number;
  edgeLimit: number;
};

const BUDGET_BY_DEPTH: Record<1 | 2 | 3 | 4, GraphBudget> = {
  1: { nodeLimit: 70, edgeLimit: 180 },
  2: { nodeLimit: 120, edgeLimit: 300 },
  3: { nodeLimit: 180, edgeLimit: 480 },
  4: { nodeLimit: 240, edgeLimit: 700 },
};

export function graphBudgetForDepth(depth: number): GraphBudget {
  const normalized = normalizeDepth(depth);
  return BUDGET_BY_DEPTH[normalized];
}
```

Replace the existing `normalizeDepth` implementation in `graph-web/src/assemble.ts` with:

```ts
function normalizeDepth(depth: number): 1 | 2 | 3 | 4 {
  if (!Number.isFinite(depth)) return 2;
  const parsed = Math.floor(depth);
  if (parsed === 1 || parsed === 2 || parsed === 3 || parsed === 4) return parsed;
  return 2;
}
```

```ts
import { graphBudgetForDepth } from "./assemble";

export function formatGraphStatus(args: {
  mode: string;
  nodeCount: number;
  edgeCount: number;
  depth: number;
  truncated: boolean;
}): string {
  const budget = graphBudgetForDepth(args.depth);
  if (args.truncated) {
    return `${args.mode} / 深度 ${args.depth} / ${args.nodeCount} 节点 / ${args.edgeCount} 边 / 已达 ${budget.nodeLimit} 节点上限，已按层保留`;
  }
  return `${args.mode} / 深度 ${args.depth} / ${args.nodeCount} 节点 / ${args.edgeCount} 边 / 上限 ${budget.nodeLimit} 节点`;
}
```
